# Web y redes de pilotos y equipos

`social-links.json` contiene enlaces revisados, asociados al `sourceId` de F1DB.
Se muestra en el encabezado de las fichas mediante `SocialLinks`.

- `website`: sitio del piloto o equipo; puede ser su perfil oficial dentro del equipo.
- `source`: página usada para contrastar sus cuentas; no se sustituye por una búsqueda.
- `reviewedAt`: fecha de revisión, no una promesa de comprobación automática.
- `links`: nombre de red y URL directa a la cuenta, sin métricas de seguidores.
- `note`: aclaración cuando se trata de canales oficiales de legado.

Antes de añadir o cambiar una cuenta, contrastar su identidad con el sitio del
piloto/equipo o con una fuente identificable. No incorporar páginas de fans,
cuentas de patrocinadores, enlaces para compartir, videos sueltos ni cuentas del
equipo dentro de las redes personales de un piloto. Conservar la distinción
entre constructores históricos y sus sucesores actuales. Una ficha sin cuentas
revisadas no muestra el bloque.
