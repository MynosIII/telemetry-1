# Logos de fabricantes de neumáticos

Los nueve fabricantes tienen un logo local comprobado visualmente. `lib/tyre-logos.json` apunta a estos archivos y conserva el enlace a su procedencia; `data/tyre-logo-sources.json` registra el nombre original. No depender de URLs remotas para mostrar las marcas.

Se priorizan variantes originales a color, sin filtros ni recoloreado del arte. Goodyear lleva un panel azul para contrastar su amarillo y Continental un panel naranja con su marca negra.

Ids: avon, bridgestone, continental, dunlop, englebert, firestone, goodyear, michelin, pirelli.
